Open decisions

  1. Diff coloring vs the red/green rule. Add/remove lines use very low-alpha green/red backgrounds plus +/− glyphs — a deliberate exception to "red/green only on verdict dots and deltas." Alternative: monochrome diff with glyphs only. Confirm the exception.
  2. Risk palette. perf = amber (shared with the policy-tier badge), correctness = blue, memory = violet (new token, appears only in the close-up sheet). Alternative: one neutral gutter color, risk carried by the text tag only.
  3. Annotation anchors use the real patch lines (model.py 325–331), not AGENT_WORKSPACE.md's illustrative 341–353. The API examples should follow the real diff.
  4. Sidebar grew to five items (Sandboxes added). No standalone "Agent" item — sessions exist only attached to a change, reached via "Test this change" / the PR page. Is a repo-level unattached session needed?
  5. Branch-row actions: kept both "Test" (opens the session) and "Review" (formal run). Alternative: "Test" only, with review as the session's escalation. Which?
  6. Eval history format: last 5 deltas, oldest → newest, latest bold; each eval reports its primary metric (tokens/s; sample_step reports p95 step latency). Confirm direction and metric choice.
  7. Sandbox economics shown: env-card estimates assume A10G ≈ $1.10/hr (~300 GPU-s ≈ $0.09); the Sandboxes table shows GPU-s + a daily ledger instead of dollar costs to avoid double-counting review costs. Confirm.
